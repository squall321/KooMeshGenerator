Usage Examples
--------------

Writing LS-DYNA Files
^^^^^^^^^^^^^^^^^^^^^

.. code-block:: python

   from koomesh.io.lsdyna_writer import LSDynaWriter

   # Initialize writer
   writer = LSDynaWriter()

   # Write mesh
   writer.write(
       mesh,
       'output.k',
       title='Crash Simulation',
       include_materials=True,
       include_contacts=True
   )

   # Write with options
   writer.write(
       mesh,
       'output.k',
       options={
           'unit_system': 'SI',  # mm, ton, s, N
           'precision': 8,
           'format': 'keyword'
       }
   )

Writing Multiple Formats
^^^^^^^^^^^^^^^^^^^^^^^^^

.. code-block:: python

   from koomesh.io import write_mesh

   # Auto-detect format from extension
   write_mesh(mesh, 'output.k')       # LS-DYNA
   write_mesh(mesh, 'output.inp')     # Abaqus
   write_mesh(mesh, 'output.bdf')     # NASTRAN
   write_mesh(mesh, 'output.vtu')     # VTK

   # Explicit format
   write_mesh(mesh, 'output.dat', format='lsdyna')

Reading Meshes
^^^^^^^^^^^^^^

.. code-block:: python

   from koomesh.io import read_mesh

   # Read from file
   mesh = read_mesh('input.msh')  # GMSH format

   # Read STEP geometry
   from koomesh.io.step_reader import StepReader

   reader = StepReader()
   shapes = reader.read('assembly.step')

   print(f"Loaded {len(shapes)} shapes")

Format Conversion
^^^^^^^^^^^^^^^^^

.. code-block:: python

   from koomesh.io import read_mesh, write_mesh

   # Read from GMSH
   mesh = read_mesh('input.msh')

   # Convert to LS-DYNA
   write_mesh(mesh, 'output.k')

   # Convert to multiple formats
   formats = ['lsdyna', 'nastran', 'abaqus', 'vtk']
   for fmt in formats:
       output = f'output.{fmt}'
       write_mesh(mesh, output, format=fmt)
       print(f"✓ Wrote {output}")

Custom Export Options
^^^^^^^^^^^^^^^^^^^^^

.. code-block:: python

   from koomesh.io.lsdyna_writer import LSDynaWriter

   writer = LSDynaWriter()

   # Customize output
   writer.write(
       mesh,
       'output.k',
       # Header options
       title='My Simulation',
       comment='Generated by KooMeshGenerator',

       # Include options
       include_materials=True,
       include_contacts=True,
       include_boundary_conditions=True,

       # Format options
       precision=8,
       field_width=10,
       use_long_format=True,

       # Unit system
       unit_system='SI',  # mm-ton-s-N

       # Part options
       part_naming='auto',  # or 'sequential', 'custom'
   )

Batch Export
^^^^^^^^^^^^

.. code-block:: python

   from koomesh.io import write_mesh

   # Export multiple meshes
   meshes = {
       'body': body_mesh,
       'door': door_mesh,
       'hood': hood_mesh
   }

   for name, mesh in meshes.items():
       # LS-DYNA
       write_mesh(mesh, f'{name}.k')

       # VTK for visualization
       write_mesh(mesh, f'{name}.vtu')

Material Export
^^^^^^^^^^^^^^^

.. code-block:: python

   from koomesh.io.lsdyna_writer import LSDynaWriter

   writer = LSDynaWriter()

   # Export with material cards
   writer.write_with_materials(
       mesh,
       'output.k',
       material_library='materials.json',
       material_mapping={
           'Part1': 'Steel_Mild',
           'Part2': 'Aluminum_6061',
           'Part3': 'Plastic_PP'
       }
   )

Contact Export
^^^^^^^^^^^^^^

.. code-block:: python

   from koomesh.io.lsdyna_writer import LSDynaWriter

   writer = LSDynaWriter()

   # Export with contact definitions
   writer.write_with_contacts(
       mesh,
       'output.k',
       contact_pairs=[
           {
               'master': 'Body',
               'slave': 'Door',
               'type': 'AUTOMATIC_SURFACE_TO_SURFACE',
               'friction': 0.3
           },
           {
               'master': 'Hood',
               'slave': 'Body',
               'type': 'TIED_SURFACE_TO_SURFACE',

CLI Usage
---------

Export Mesh::

   # Export to LS-DYNA
   koomesh export mesh.msh output.k

   # With materials
   koomesh export mesh.msh output.k --include-materials

   # With contacts
   koomesh export mesh.msh output.k --include-contacts

Format Conversion::

   # Convert formats
   koomesh convert input.msh --to lsdyna -o output.k

   # Batch conversion
   koomesh convert *.msh --to lsdyna --output-dir lsdyna_files/

   # Multiple formats
   koomesh convert input.msh --to lsdyna,nastran,abaqus

Import Geometry::

   # Import STEP file
   koomesh import geometry.step

   # Batch import
   koomesh import *.step --output-dir meshes/

Export Options
--------------

Precision Settings
^^^^^^^^^^^^^^^^^^

.. code-block:: python

   # Low precision (faster, smaller files)
   writer.write(mesh, 'output.k', precision=4)

   # High precision (better accuracy)
   writer.write(mesh, 'output.k', precision=16)

   # Standard
   writer.write(mesh, 'output.k', precision=8)  # Default

Field Width
^^^^^^^^^^^

.. code-block:: python

   # Standard format (8 characters)
   writer.write(mesh, 'output.k', field_width=8)

   # Long format (16 characters)
   writer.write(mesh, 'output.k', field_width=16, use_long_format=True)

Unit Systems
^^^^^^^^^^^^

.. code-block:: python

   # SI: mm, ton, s, N
   writer.write(mesh, 'output.k', unit_system='SI')

   # CGS: cm, g, s, dyne
   writer.write(mesh, 'output.k', unit_system='CGS')

   # Imperial: in, lbf*s²/in, s, lbf
   writer.write(mesh, 'output.k', unit_system='Imperial')

Troubleshooting
---------------

Common Export Issues
^^^^^^^^^^^^^^^^^^^^

**Issue**: "Unsupported element type"

**Solution**: Convert to supported type::

   koomesh convert mesh.k --element-type tet4

**Issue**: "File too large"

**Solution**: Use compression or split::

   koomesh export mesh.msh output.k --compress
   # Or split into parts
   koomesh export mesh.msh output.k --split-parts

**Issue**: "Material not found"

**Solution**: Specify material library::

   koomesh export mesh.msh output.k \
       --materials materials.json \
       --default-material Steel_Mild

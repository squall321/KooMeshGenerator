Contributing Guide
==================

Thank you for your interest in contributing to KooMeshGenerator!

How to Contribute
-----------------

1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Run tests
5. Submit a pull request

Development Setup
-----------------

::

   git clone https://github.com/yourorg/KooMeshGenerator.git
   cd KooMeshGenerator
   pip install -e .[dev]
   pytest tests/

Coding Standards
----------------

- Follow PEP 8
- Add docstrings (Google style)
- Write tests for new features
- Update documentation

Pull Request Process
---------------------

1. Update tests
2. Update documentation
3. Run full test suite
4. Create descriptive PR

Contact
-------

- GitHub Issues

### 1. Automotive Crash Simulation

**File**: `complete_workflows/automotive_crash.py`

**Description**: Multi-part vehicle crash simulation with contact detection.

**Features demonstrated**:
- Loading multiple STEP files (vehicle components)
- Multi-body contact detection
- Material assignment recommendations
- LS-DYNA crash setup
- Progress tracking

**Run example**:
```bash
cd examples/complete_workflows
python automotive_crash.py
```

**Expected output**:
- `output/automotive_crash.k` - LS-DYNA keyword file

- Contact detection results
- Material and simulation recommendations

**Use cases**:
- Vehicle crashworthiness analysis

## 📝 Customization Guide

### Modifying Mesh Size

```python
# Coarse mesh (faster, less accurate)
config.mesh_size = 20.0  # 20mm

# Medium mesh (balanced)
config.mesh_size = 10.0  # 10mm

# Fine mesh (slower, more accurate)
config.mesh_size = 5.0   # 5mm
```

### Element Type Selection

```python
# Tetrahedral (complex geometry)
config.element_type = 'tet4'

# Hexahedral (structured)
config.element_type = 'hex8'
```

### Quality Thresholds

```python
# Recommended for crash
config.min_quality_threshold = 0.4
config.target_quality_threshold = 0.6

# Recommended for forming
config.min_quality_threshold = 0.4
config.target_quality_threshold = 0.7
```

## 🐛 Troubleshooting

### Issue: "Poor mesh quality"

**Solutions**:
1. Reduce mesh size: `config.mesh_size = 5.0`
2. Enable auto-remeshing: `config.enable_auto_remesh = True`
3. Clean geometry: `config.clean_geometry = True`

### Issue: "No contacts detected"

**Solutions**:
1. Increase contact tolerance: `config.contact_tolerance = 1.0`
2. Enable verbose mode: `config.verbose = True`
